# Предложение плагина
Для предложения нового плагина нужно создать **Issue** в репозитории. В нем обязательно должны присутствовать:

### Основная информация
- Название проекта
- Описание проекта
- Автор проекта
- Планируемая дата релиза

### Описание преимуществ
- Что будет реализовано
- Для чего предназначен плагин
- В чем его практическая польза

После завершения разработки плагина необходимо создать **Pull Request**
