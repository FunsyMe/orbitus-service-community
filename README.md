### Предложение плагина - Issue
Перед началом разработки необходимо создать **Issue** с идеей Вашего плагина, выбрав шаблон `⚙️ Заявка на плагин ⚙️`

> [!NOTE]
> Создание Issuse обязательно, без него Ваш плагин не будет принят. Это предотвращает дублирование функционала плагинов

---

### Публикация релиза - Pull Request
После завершения разработки и тестирования создайте **Pull Request** из вашего форка
> [!IMPORTANT]
> Все плагины проходят проверку на безопасность.
> Наличие вредоносного кода или обфускации может повлечь за собой ответственность
